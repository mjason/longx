HTTP 服务

默认仅允许本机访问。启动服务后，在 Longx 中连接。

远程设备必须使用访问密钥。HTTP 不加密；只在可信网络使用，跨不可信网络请通过 HTTPS 反向代理或加密隧道访问。还需自行配置防火墙。

连接 Longx

在 Longx 设置 → Agent kernel 中填写上面的地址和访问密钥。本机与远程使用相同接口。

截图可能含私人信息，会传给 Longx 的模型并保存在会话中。CUA 默认开启不含内容的产品遥测，本应用不自动修改该设置。
