# Computer use via Longx Computer

Computer automation lives in an independent Tauri 2 app under `apps/computer/`.
Longx no longer installs or launches CUA Driver. Settings → Agent kernel saves
a service URL and access key, then explicitly connects. The same HTTP MCP
client works against a local or remote computer.

Default URL: `http://127.0.0.1:7797/mcp`. The app lets the person choose an IP
address and port; non-loopback listening and foreground/full-display control
are explicit opt-ins. Firewall configuration is not changed. Always authenticate;
use HTTPS via a reverse proxy or an encrypted tunnel across untrusted networks.
Plain HTTP is only for trusted networks.

The access key is generated by the app and stored in its OS credential store.
The person enters it into Longx's masked settings field. Longx encrypts it at
rest (`computer_service` Setting); settings returns only URL and key presence,
never the value. Leaving the key empty preserves it only for the exact saved URL;
changing targets requires an explicit key. Saving disconnects the old service.
Keys, screenshots and desktop contents are not logged. No automatic redirects
or retries are performed.

## Desktop application

See `apps/computer/README.md` for packaging, signing and use.
The app embeds pinned/checksummed CUA Driver 0.32.0 and runtime helpers,
not a second CuaDriver.app or another agent/model runtime.

On macOS a signed `com.longx.computer` app directly spawns `serve --embedded`;
it owns the responsibility chain and both Accessibility/Screen Recording grants.
It requests permission through host APIs and guides the user to System Settings.
Driver uses a private socket. A parent-liveness pipe ends it if the host dies.
On Windows run in the logged-in interactive desktop, not Session 0.
Linux requires the graphical user's display and accessibility bus; Wayland
portal permissions may still be per-session. These platform limitations do not
disappear by putting a GUI around the Driver.

The app owns HTTP, control status, global desktop exclusivity, credential
revocation and a local/tray stop button. Closing the window hides it to the tray;
Quit stops the owned runtime. An explicit service restart invalidates old sessions.
Unexpected Driver exit stops accepting control, not a false-ready service.

## Protocol and lifecycle

JSON-RPC POST `/mcp`, legacy MCP `2025-06-18`, Bearer auth.
Initialize returns `Mcp-Session-Id`; subsequent calls and DELETE include it.
Each HTTP session owns a persistent private stdio MCP proxy inside the app.
Sessions therefore survive TCP reconnection; CUA's original TCP-scoped HTTP
endpoint is not exposed. Missing/expired sessions return 404, requiring a new
connection and observation. Input is never automatically replayed.

All clients share one desktop lease. A public Driver session label is scoped
under the authenticated HTTP session; it cannot select another client's session.
Idle sessions expire after 90 seconds. Longx sends a monitored ping every
15 seconds and invalidates ready state when it fails. DELETE closes the
client/proxy and releases its lease. Lost/cancelled responses may already have
applied, so reconnect and independently observe before continuing.

The service rejects browser Origin requests, exposes no CORS, bounds request and
Driver-response sizes, curates tools, and strips output-path/internal-session
arguments. Background-mode window observations omit app/global menu subtrees
(which can otherwise contain unrelated recent-item names), preserving tokens
and images. The user's authorization still determines which apps/data/tasks
may be operated.

## Computer plug

Add `plug Computer` to the project's `.longx/local/agent.exs` agent block.
Default pipeline is unchanged. The plug adds `computer_status` and the connected
service's curated native schemas with the `computer_` prefix.
Screenshots go to the selected model and are retained as conversation attachments.
Prefer a requested window to full-display capture.

One Longx turn owns its connection's desktop lease. Observe before input;
preserve the Driver's opaque fresh tokens, capture geometry and effect diagnostics.
Actual turn completion or Agent exit releases ownership, including stop/failure
paths (not only the plug's turn-end phase). Interruption, timeout or session loss
invalidates the observation and connection. Foreground/full-display control must
be enabled in both Longx and the app, never silently escalated.

Earlier downloaded standalone packages and the old encrypted `computer_http`
setting are retained on disk but no longer used. No old shared Driver is
automatically stopped. Migration requires installing the independent app and
entering its URL/key.

CUA Driver is MIT-licensed; its packaged licenses/notices are retained.
Optional perception and CUA Spaces are not included. CUA's default content-free
telemetry is disclosed, not silently changed.
